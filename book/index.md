# Urban Twin Lab

![JupyterLite + GPT-6 Astra Geospatial](assets/geospatial-splash.svg)

Sixteen browser-sized experiments for exploring geospatial reasoning, urban digital twins and 3D mapping. Read the explanations and example outputs here, then open the matching JupyterLite notebook to change parameters and run the calculations yourself.

**[Launch JupyterLite](https://jltobias.github.io/JupyterLite-GPT-6-Astra-Geospatial/lite/lab/index.html)** · **[Experiment gallery](https://jltobias.github.io/JupyterLite-GPT-6-Astra-Geospatial/index.html)** · **[GitHub repository](https://github.com/jltobias/JupyterLite-GPT-6-Astra-Geospatial)**

All city data are synthetic. Astra prompts are optional experiments, not paid API calls or a language model running in the browser. The book's outputs were captured during desktop validation; performance timings describe that build environment, not your device. Run notebook 10 in JupyterLite to measure your browser.

## Suggested routes

- **Spatial foundations:** 01 coordinates → 02 population → 03 network access.
- **Urban interventions:** 04 heat → 05 disruption → 06 mobility.
- **Dynamic twins:** 07 observations → 08 learned world model.
- **AI and performance:** 09 evaluate Astra → 10 compare Rust/WASM.
- **Evidence and evaluation:** 11 raster change → 12 equitable siting → 13 repeated spatial trials.
- **Interactive 3D mapping:** 14 MapLibre buildings → 15 deck.gl access layers → 16 Plotly terrain.

The teaching chapter includes workshop routes, copyable tasks and a rubric. The 3D scenes use synthetic data and load their JavaScript renderers from CDNs; download their HTML exports for sharing. Static plots and tables support learners whose devices cannot render WebGL.

Each chapter includes assumptions, working code, checks and a next experiment. See the research guide for the distinction between a toy simulator, a learned world model and a data-conditioned digital twin. The sources page records all inputs, citations, attribution and licensing boundaries.
